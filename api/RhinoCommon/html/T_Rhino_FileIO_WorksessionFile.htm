WorksessionFile Class

Reads and writes Rhino worksession (.rws) files. A worksession file lists models and a worksession's layer overrides. It does not contain any model content, and nothing here opens or checks the model files it lists.

Remarks
Rhino 4 wrote version 4 files. Rhino 5 and later write version 5. Both versions can be read and written. Models are exchanged by value: GetModel(Int32) returns a copy, and changes to it are kept only after SetModel(Int32, WorksessionFileModel).
