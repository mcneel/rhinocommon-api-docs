Remarks
This needs second order surface derivatives. They are available throughout the corner quad of an extraordinary vertex, but not exactly on such a vertex: a SubD limit surface is C1 there but generally not C2, so it has no curvature. This returns false in that case, and kappa1 and kappa2 are NaN.
