MeshCurveIntersection Class

One certified hit from a curve-mesh intersection. Either a single isolated crossing (IsPoint) or a parameter range over which the curve lies in a face's plane (IsOverlap). For a point hit, CurveParameter is degenerate and PointA equals PointB. In a results array, every overlap is reported as two Point hits at its endpoints plus one Overlap hit for the span. The *Tolerance properties are certified half-widths derived from interval enclosures.
