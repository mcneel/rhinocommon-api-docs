MeshSetCachedTextureCoordinatesFromMaterial Method (File3dm, Guid, Material)

Sets up cached texture coordinate set for each texture in the material. Textures in the Material define which mapping channels are used and the object with the specified id in the file defines what texture mapping is used for each mapping channel. After this method is called all necessary texture coordinate sets are cached and correct texture coordinates for each texture can be fetched using GetCachedTextureCoordinates(File3dm file, Guid objectId, Rhino.DocObjects.Texture texture) If any texture coordinates are already cached they will not be re-computed.
