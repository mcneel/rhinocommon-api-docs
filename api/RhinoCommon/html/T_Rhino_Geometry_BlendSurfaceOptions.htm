BlendSurfaceOptions Class

Settings for CreateBlendSurface(BrepFace, BrepEdge, Interval, Boolean, BrepFace, BrepEdge, Interval, Boolean, BlendSurfaceOptions, Double). The defaults give the result of the BlendSrf command when its dialog is accepted unchanged. Properties ending in 0 apply to the first edge, those ending in 1 to the second.

Bulge0
Scale factor for the blend's tangent lengths at the first edge, the Bulge setting of BlendSrf. Must be greater than zero. The default is 1.0.
Bulge1
Scale factor for the blend's tangent lengths at the second edge, the Bulge setting of BlendSrf. Must be greater than zero. The default is 1.0.
Continuity0
Continuity of the blend at the first edge. The default is Curvature.
Continuity1
Continuity of the blend at the second edge. The default is Curvature.
InteriorShapes
True to add blend shapes at the edit points of the edges when the edges are compatible, the Interior shapes setting of BlendSrf. Has no effect when Refine is true. The default is true.
PlanarSectionDirection
Direction the planar sections are parallel to. Used only when PlanarSections is true. Must be a valid, nonzero vector. The default is the world z axis.
PlanarSections
True if every blend shape lies in a plane parallel to PlanarSectionDirection, the Planar sections setting of BlendSrf. The default is false.
Refine
True to fit the blend to tolerance instead of making the simple blend that compatible edges allow, the Refine setting of BlendSrf. The default is false.
SameHeight
True to give every blend shape the height of a shape spanning the average of the gaps at the two ends of the blend, the Same height setting of BlendSrf. The default is false.
