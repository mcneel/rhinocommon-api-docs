IntersectionMeshMeshPredicate Method (IEnumerableMesh, Double, Int32, TextLog)

Determines which meshes intersect. No geometry is computed: each pair of meshes is tested only until its first crossing is found, with the fast intersector behind MeshMeshFast(Mesh, Mesh). Faces that cross or touch within tolerance count; coplanar overlap without a crossing does not.

The same as MeshMeshPredicate(IEnumerableMesh, IEnumerableMesh, Double, Boolean, Int32, Int32, TextLog, CancellationToken) with fast = true.
