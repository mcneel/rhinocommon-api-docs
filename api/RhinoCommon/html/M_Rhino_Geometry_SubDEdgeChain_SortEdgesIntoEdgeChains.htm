The edges to sort. Where three or more of them meet at one vertex, no chain passes through that vertex.

Return Value

Type: SubDEdge
One array of edges per chain, in chain order. Each returned edge carries the direction its chain traverses it with.
Remarks
This uses the mark bits on the edges and vertices involved, so it must not run on the same SubD from more than one thread at a time.
