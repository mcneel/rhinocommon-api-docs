CancellationToken
A token that allows to request the cancellation of the operation.
CompleteOpenCuts

Gets or sets whether cuts that stop inside the mesh are completed.

An intersection curve that stops inside the mesh does not separate one side from the other, so the mesh is returned whole. When this is enabled, each such open end is joined to the nearest border of the mesh, or to another cut, following edges the mesh already has.

This yields a best-effort cut where the intersection alone leaves the answer undetermined: the added stretch follows existing edges rather than the cutter, so it is not an intersection result. No vertex is moved and no face is added. Cuts that already close, or that already run from border to border, are unaffected.
